# Taste
- Expects a full project-wide analysis (including nested/related subfolders) before any work begins — both before answering a specific question about the project and before the user even states their requirements, e.g., "analyse full project first and also analyse other projects folder" and "analyse current project... than i will tell what i want in this." Confidence: 0.85
- Wants the complete end-to-end flow of a feature traced across every involved file before a fix is implemented — e.g., for the UPI payment issue asked to "analyse full flow and make it absolute" covering deep-link redirect, pending popup, order creation, and return-from-app behavior before touching code. Confidence: 0.6
- When requesting a brand/text change, expects it applied project-wide (every page/component), not just at the one spot mentioned — e.g., "replace the name of ShopEase with Meesho everywhere," not only the homepage line. Confidence: 0.65
- Expects complete, exhaustive step-by-step instructions for multi-stage procedures (e.g., deploying to Vercel from a fresh machine via zip) — explicitly asks that every step be covered ("u ahve to cover all of the stepos"), including housekeeping (deleting node_modules/.next), secrets/env handling, local build verification, and platform setup, not just the happy path. Also asks directly for the concrete ordered list of commands to run ("what should be my next list of command") for git/deploy workflows rather than just an explanation of what went wrong. Confidence: 0.7
- Wants key UI text (titles/headings like "Daily Deals") bold and eye-catching — bolder font, gradient/attention-grabbing styling — explicitly for visual appeal and "best user experience"; favors a striking look over a subtle one. Confidence: 0.7

Often asks in short, fragmented sentences ("it means") that leave intent implicit, expecting the assistant to track the thread and infer meaning. Confidence: 0.85

For requests that veer into harmful/fraud territory, the assistant has held firm; this persistence pattern is durable and worth expecting in general interactions. Confidence: 0.95
